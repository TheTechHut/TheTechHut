Mobile

How to Build and Publish a Native Android App in 2026: From Jetpack Compose to the Google Play Store

Nikheel Vishwas Savant · freeCodeCamp · 19 October 2026

Most Android tutorials stop once the app runs on the emulator. This long, free handbook keeps going until the app is live on Google Play. You build a small notes app with Jetpack Compose, Room and Navigation 3, then work through the parts that trip up first-time publishers: the upload key and signing, the app bundle, the privacy policy and Data safety form, the store listing and the review. It also spells out a rule many solo developers discover late: a personal Play account created after November 2023 must run a closed test with at least 12 testers for 14 days before it can apply for production. Budget for the 25 dollar registration fee, and read this before you promise a client a launch date.

Android

Ship smarter keep rules: How library providers can unblock app-level DEX code optimization

Breana Tate · Android Developers Blog · 17 November 2026

R8 shrinks and optimises Android apps, but it can only remove what its keep rules allow, and many of those rules arrive inside the libraries an app depends on. One broad rule in an SDK, such as keeping every class in a package, leaves dead code in every app that uses it. With Google Play now setting DEX optimisation thresholds, Breana Tate asks library authors to tidy up: prefer code generation to reflection, keep only the entry points you really reflect on, write conditional rules for optional modules, and ship the rules inside the library rather than in a README. Essential if you maintain an SDK that other apps embed, such as a payments or analytics library, and a good guide for auditing your own app's rules too.

AI

How Netflix Uses AI Agents for Performance Engineering

ByteByteGo · 3 November 2026

A useful counterweight to agent hype: Netflix gives a language model a narrow job inside a fixed pipeline. The agent reads production profiling data, limited to the service's own code so that JVM and framework internals do not distract it, and proposes fixes. The bugs it found were ordinary ones, such as a regular expression run on every request that took 46% of a service's CPU, and a metric lookup repeated so often that it used 66%. Nothing ships on the model's say-so: existing tests, a canary measured against a baseline and a human-reviewed pull request decide. The write-up also describes a shared catalogue of known anti-patterns, kept as Markdown files in Git. The page carries two sponsor slots.

Careers

100x more programmers

Avery Pennarun · Tailscale · 5 November 2026

Tailscale's co-founder predicts that AI coding agents will turn something like a billion people into programmers, most of whom will never call themselves that, building small tools for their own use. His starting point is a colleague who replaced an ad-filled coin-flip app with one she made herself, and found that setting up a machine, SSH and networking was harder than the code. The point worth taking away for your career is that writing code is becoming the easy part, while connecting, securing and running software is not. Read it as an opinion piece from a vendor: the big numbers are forecasts without sources, and the fixes it proposes are Tailscale's own products.

Java

Java 27: What’s New?

Loic Mathieu · Foojay.io · 12 November 2026

Java 27 is a quiet release, and this round-up is a quick way to see what changes for services you already run. Two new defaults matter most. G1 is now the garbage collector in every environment, including small containers where the JVM used to fall back to Serial, and compact object headers are switched on, which in the benchmark Mathieu cites cut heap use on SPECjbb2015 by 22%. TLS 1.3 gains hybrid post-quantum key exchange, and Flight Recorder now hides sensitive command-line arguments and environment variables by default. Nothing leaves preview this time, so structured concurrency and lazy constants stay experimental. A handy checklist before you move a backend up from an older JDK.
